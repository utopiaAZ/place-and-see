# 퍼즐 규칙

Stage 1의 상세 규칙은 아래에, Stage 2와 Stage 3 복합 규칙은 각각 [Stage 2 규칙](STAGE_002_RULES.md),
[Stage 3 규칙](STAGE_003_RULES.md)에 분리해 기록합니다. 각 Stage는 독립 RuleSystem을 사용합니다.

## Stage 1

## 목표

물병의 `zoneId`가 `desk-surface`이고 방향이 `upright`인 상태를 Core 가상 시간 기준 3초 동안
연속으로 유지하면 완료됩니다. 물병을 집거나 넘어뜨리면 안정성 시간이 0으로 초기화됩니다.

## 기본 인과관계

준비 없이 물병을 책상에 두면 고양이가 250ms 뒤 감지하고 관심, 점프 준비, 점프, 앞발 공격을
결정적으로 진행합니다. 물병은 흔들린 뒤 3초 전에 넘어지고 물웅덩이가 남습니다. 스테이지는 자동
리셋되지 않아 플레이어가 원인을 관찰하고 물병을 다시 집어 재시도할 수 있습니다.

## 세 가지 해결법

- 간식: 바닥에 놓으면 고양이가 영구적으로 간식에 집중합니다. 사용 중에는 이동할 수 없습니다.
- 장난감 쥐: 바닥에 놓으면 고양이가 5초간 놀고 돌아옵니다. 그 안에 3초 안정성을 채워야 하며 이후 재사용할 수 있습니다.
- 미끄럼 방지 매트: 매트를 먼저 책상에 놓으면 물병이 지지됩니다. 고양이는 공격하지만 물병이 짧게 흔들린 뒤 똑바로 유지됩니다.

`noticing-bottle`과 `preparing-jump`에서는 간식/장난감이 공격을 즉시 취소합니다. `jumping`과
`tapping-bottle`에서는 현재 공격이 끝난 뒤 주의 분산 행동을 시작합니다. 물병이 올라간 매트와 고양이가
사용 중인 도구는 Core가 입력 잠금 상태로 관리합니다.

## 시간과 표현의 책임

규칙 시간은 `ADVANCE_TIME` Command와 `StageOneRuleSystem`만 사용합니다. Phaser Tween 완료 콜백이나
브라우저 타이머가 결과를 결정하지 않습니다. Phaser는 고양이 rig, 물병 흔들림/넘어짐, 드롭 피드백을
Core Event에 맞춰 재생하고 React는 Bridge의 읽기 전용 snapshot으로 상태와 진행률만 표시합니다.

Core Event는 의미 기반 `SoundEvent`로 변환됩니다. 매니페스트에 대응 파일이 없을 때 `AudioManager`는
재생을 안전하게 생략합니다.
